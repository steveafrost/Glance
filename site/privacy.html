Glance

Privacy

Last updated 11 November 2026

Glance does not collect, transmit or share any information about you. This is not a promise about how we behave; it is a property of how the app is built, and you can check it.

What the app does with your data

Glance reads your calendars through macOS EventKit, the same system framework Calendar.app uses. Events are read into memory and drawn on screen. Nothing is written anywhere except the changes you make: when you create or edit an event, Glance asks EventKit to save it to your calendar, which is where it already lives.

The app stores its own settings — theme, menu bar format, which calendars are visible — in your user defaults on your Mac. Those never leave the machine.

No network access

  • The App Store build is sandboxed without a network entitlement, so macOS itself prevents an outbound connection.
  • There is no analytics SDK, no crash reporter, and no third-party code of any kind in the app.
  • Nothing is sent to us, because there is nowhere for it to go.

Updates are delivered by the App Store under Apple's terms, not by Glance.

What we do not do

  • No account, sign-in or email address is required or requested.
  • No usage data, diagnostics or telemetry is collected.
  • No advertising, tracking or profiling.
  • No data is sold or shared, because none is gathered.

Calendar access

macOS asks for permission before any app can read your calendars. You can decline and Glance will still run, showing its month grid without events. You can change your answer at any time in System Settings › Privacy & Security › Calendars.

This website

glancecal.com is a static site with no cookies, no analytics and no third-party requests. It loads its fonts and images from its own domain.

Children

Glance is not directed at children and collects no personal information from anyone, including children under 13.

Changes

If this policy ever changes, the date at the top changes with it. Because the app cannot send data anywhere, a future version could only collect something by adding networking code — which would be visible in the source and in the app's entitlements.
